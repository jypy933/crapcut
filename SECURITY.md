# Security policy

Please report security problems privately through GitHub:
**Security -> Report a vulnerability** on
[jypy933/crapcut](https://github.com/jypy933/crapcut/security/advisories/new).
Do not open a public issue for security problems.

You can expect a first answer within a week. Fixes ship as a new release; the
app updates itself from GitHub Releases.

Supported versions: the latest release only.

See [docs/architecture.md](docs/architecture.md#security) for how the app is
hardened.
